# Behind the Drop — three proof-of-concept directions

Three single-page proof-of-concept designs for an Apex Legends–styled talk deck, built to pick a
visual direction. **Open the live comparison:** https://trmwil.github.io/behind-the-drop/

- Click **Open full screen** on a direction, press F11 (⌃⌘F on a Mac), and step through the
  four beats with the arrow keys. The transitions between beats are the point.
- **A — Broadcast** · **B — Cover Story** · **C — Drop Sequence**. Each has a short note in `poc/`.
- All three share the same content (a placeholder title, public Apex facts, the Legend roster,
  the Season 30 "Marked" gameplay trailer from the Steam store page) so only the direction differs.
- Body copy, pull quote and closing line are placeholders.
